# Amara Sumi D. Erorita — Portfolio

A static, single-screen portfolio prepared for GitHub Pages.

## Pages
- `index.html` — Home (portrait, essential profile information, and navigation only)
- `personal-information.html` — Personal Information
- `achievements.html` — Academic journey, extracurricular achievements, photographs, and organizations
- `friends-family.html` — Reserved page for future content

## Design notes
- All pages are designed to fit within one viewport without page scrolling.
- Navigation is consistent across all pages.
- The achievements gallery includes the trophy awards, group certificate photograph, certificate photograph, and guest-speaking photograph.
- The running medals/race-bib photograph is intentionally excluded.
- Local images and styles are stored in `assets/`.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder (not just the ZIP file).
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Open the published URL shown in the Pages settings.
